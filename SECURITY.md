# Security Policy

## Supported Versions

AXIS is currently an active scientific research and development project. Security fixes are applied directly to the main branch.

| Version | Supported          | Status |
| ------- | ------------------ | ------ |
| 0.1.x   | :white_check_mark: | Active Research Preview |
| < 0.1   | :x:                | Legacy / Archived Research Phases |

## Reporting a Vulnerability

We take the security of this project, its pipelines, and its data management very seriously. If you discover a security vulnerability, please follow these instructions:

### 1. Private Disclosure
**DO NOT open a public issue** on GitHub for security vulnerabilities, exposed credentials, or data privacy risks.

Instead, please report security vulnerabilities privately via email to:
`teobarreau7@gmail.com`

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a minimal proof-of-concept
- Any relevant logs, scripts, or configuration files

### 2. Response Timeline
- **Initial Acknowledgement:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Resolution / Patch:** As quickly as possible depending on complexity.

## Data Governance and Intellectual Property
- **Datasets:** Large raw datasets and copyrighted architectural corpora are strictly quarantined and never committed to this repository.
- **Credentials:** No API keys, credentials, or private SSH keys are stored in the codebase.
- If you notice any accidental leakage of private architectural assets or credentials, please report it immediately via the contact email above.
